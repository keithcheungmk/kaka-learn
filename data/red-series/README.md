# 紅輯書本 manifest

每本 JSON 係紅輯遊戲嘅內容交接資料。`cardsFile` 指向已核對嘅認字卡資料；`sourcePdf` 只作來源追溯，唔會由網站直接載入。

`contentStatus: cards-verified` 只代表字卡內容已核實，唔代表有權由字卡推造書頁句子。新版「按書頁砌句」唯一題目來源係 `sentence-game-data.mjs`：只有 `sourceVerified: true` 嘅逐頁題目先可玩；其他書可以預覽掃描頁，但未核實前不會生成詞槽、選項或星星測驗。

截至 2026-09-17，《分果果》已接入 3 個整跨頁任務：PDF p4、p5 各四組詞語，p6 左頁兩組詞語，按組數各派 4、4、2 星，合共 10 星。p6 右頁印句未完，已排除並為遊戲另存左頁裁圖。

《誰在叫》已加入 PDF p5（書內第 2–3 頁）完整故事跨頁：左句使用原頁「吱，吱，吱」、右句使用「喵，喵，喵」，共十個詞組；重複象聲詞及「誰在叫」均保留為獨立選項，另加四個取自 p6 的干擾詞。PDF p4 字卡／封面頁已明確排除。其餘十本保持 `mode: preview`，等待逐頁轉錄與複核。
