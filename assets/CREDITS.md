# 卡卡字母隊字母音

`assets/phonemes/{a–z}.mp3` 目前由家庭錄音剪輯（一條 a–z 連續檔，按約 2 秒一格切開），
唔用第三方教材原檔上線。呢套錄音正按 `docs/phonics-audio-standard.md` 重新驗收；未完成前唔可以標示為
Open Source Phonics 錄音。

重新錄製採用 Open Source Phonics 的純音教學方法作參考（CC BY-NC-SA 4.0）：
https://www.opensourcephonics.org/terms-of-use/ 。網站提供課程及發音指引，並無複製其音檔。
