# 卡卡常識樂園圖像來源

- `mtr-family-map.svg`：自製兒童向港鐵**示意**圖，只標家庭錨點同幾個出名站，**非官方路線圖**，唔複製港鐵版權地圖。
- `scenes/*.webp`：卡卡風格 4:3 場景插圖，用角色設定圖生成，答題同學習牆共用。職業包十張答題圖按現有 `assets/careers/` 肖像重畫成 4:3 橫向場景（檔名仍係 yisheng／hushi 等）；中文／英文職業字卡繼續用方形 `assets/careers/`。
- `icons/*.svg`、`process/*.svg`：學習牆／過程卡仍可用嘅簡約貼紙風 SVG；答題圖已改用 `scenes/`。
- `comics/*.webp`：用卡卡／禧禧／傑叔叔既有角色設定圖生成嘅原創面試四格，無文字無商標。
