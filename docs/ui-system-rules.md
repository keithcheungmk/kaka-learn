# KAKA Learning App：跨科 UI System Rules

呢份規格係數學、英文、中文三組共用嘅 UI 交付標準。任何新頁面或遊戲改動，合併前都必須符合以下規矩。

## 目標裝置

- iPad Pro 11 橫向：`1210 × 834`（主要設計基準）
- iPad Pro 11 直向：`834 × 1210`（採用手機式流體 layout）
- iPhone 16 Pro Max 直向：`430 × 932`
- iPhone 橫向亦不可水平溢出；以流體寬度自然收縮。

## 版面與觸控

- 禁止固定頁面高度；內容不足一屏時仍可自然垂直捲動。
- `scrollWidth` 不得大於 `clientWidth`，禁止水平捲動。
- Grid／Flex 必須使用流體尺寸（例如 `minmax()`），不可依賴固定卡片寬度。
- 主要按鈕、答案選項、拖放目標最少 `44 × 44px`，相鄰控制至少相隔 `8px`。
- 拖放玩法必須同時支援 tap／click；選取、答錯、答對、提交及下一題要有清晰狀態。
- 內容較長時增加垂直空間，不可壓縮到 K2 看不清楚。

## 媒體與動畫

- 影片統一使用 `controls playsinline` 及穩定 aspect ratio；不可裁切主要口形或文字。
- 影片不可由程式強制靜音；自動播放被瀏覽器阻止時，使用者按播放後必須有聲。
- 同一時間只播放一條獨立音訊，避免重疊。
- 星星／答對動畫不可遮住題目、答案或控制區。

## 合併前回歸閘門

每組 lead 必須在三個 viewport 完成受影響流程，並記錄：

1. 無水平溢出、裁切、卡片重疊或非預期 nested scroll。
2. 主要控制達到 44px、tap／drag 均可操作。
3. 至少完成一題答錯、答對、下一題及星星增加。
4. 影片有聲、音訊不重疊、動畫完成後版面仍穩定。

Lead 自我檢查後，由 chief lead 做跨科規格檢查，通過先可以 merge／deploy。
