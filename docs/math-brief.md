# 小鹿數理探險 — 產品大綱與風格（Phase 0）

給 KAKA（約 4 歲／升 K2）嘅**獨立**數學＋邏輯學習頁規格。  
**本檔係規格，未實作遊戲畫面。**

參考（教學邏輯，唔抄產品形態）：[KooBits 香港](https://www.koobits.com/hk) — 短每日節奏、CPA、獎勵、由淺入深。

---

## 硬性分離（同認字／字母隊永遠分開）

數理**唔係**認字 App 或多一個「模式」，亦**唔好**再走字母隊咁嵌進同一個 `index.html` 主循環。要有機制令三者長期分開：

| 層面 | 規則 |
|------|------|
| **頁面／入口** | 獨立頁（建議 `math.html` 或 `math/index.html`）。認字主頁最多放「去數理」外連；數理頁唔載入認字／字母隊 game screens。 |
| **程式** | 只用 `js/math-*.js`、`css/math.css`（及數理專用 assets）。**禁止** import／呼叫 `words.js`、`app.js`、`phonics-*.js` 嘅題目／畫面邏輯。可共用嘅只有真正無關遊戲嘅薄工具（例如之後抽出嘅 TTS helper）；預設寧願數理自帶 `math-speech`／自複用，都唔好同認字 state 綁死。 |
| **資料** | 獨立 `localStorage` 鍵（例如 `kaka-math-v1`）：星球進度、數理星星、數理家長設定。**唔寫入** `kaka-learn-v1`。認字每日星星同數理每日星星分開計。 |
| **家長鎖** | 數理可自設 PIN（預設可同 `1234` 方便屋企），但存喺數理自己嘅 storage；唔同認字 PIN state 共用同一個 object。 |
| **視覺／角色** | 數理專用更 Q 小鹿、八色星球、獨立動畫；唔複用認字 hero 鹿 DOM／字母隊 letter-tile 系統。 |
| **Agent／PR** | 改數理只動數理檔同本 brief／AGENTS 相關段；唔好喺同一個 feature PR 撈埋改認字主題或 phonics 詞庫。反之亦然。 |

一句：**三個學習面（認字｜字母隊｜數理）＝三套產品邊界**；同 repo 只係方便部署，唔代表同一個 App 狀態機。

## 網頁大綱（資訊架構）

數理自己嘅單頁 App；**進度隱喻＝溫柔星球旅程**（軟解鎖，可返舊星）。認字主頁若加入口，只係連去呢頁。

```
math.html（獨立）
 └─ 小鹿數理探險
      ├─ 太空站 hub（而家呢粒星球為大；下一個淡示；可睇旅程）
      ├─ 登陸星球 → 先學一學（CPA：卡通物件 + 粵語短講）
      ├─ 去玩玩
      │    ├─ 聽一聽・揀圖
      │    ├─ 數一數・揀數
      │    ├─ 拖一拖・分類／比較
      │    └─ 砌一砌・補規律（可後加）
      ├─ 點亮星球 → 短飛行動畫 → 建議下一粒
      └─ （Phase 2）挑戰小行星「面試小試」— 家長開關
```

### 畫面清單（MVP 骨架）

1. **`screen-math-hub`** — 太空站：當前星球大、小鹿導遊、出發掣；細掣「睇旅程」
2. **`screen-math-galaxy`**（可後做）— 極簡 8 星球軌道總覽；已點亮 vs 未到訪
3. **`screen-math-learn`** — 先學：中央大視覺、🔊 再聽、上一張／下一張
4. **`screen-math-play`** — 揀玩法（大掣）
5. **`screen-math-listen` / `count` / `sort`** — 各玩法一屏
6. 數理自用：頂欄返 hub、數理星星面板、溫柔 feedback、過關飛行動畫層

家長區（數理頁內，後加）：開關技能／星球、面試模式、數理每日星星上限（可同樣 10，但計數獨立）。  
**過關條件（幼齡）：** 喺該星答啱約 5 題或完成一輪玩即可點亮；唔設正確率門檻。  
**進度：** 星球點亮同數理星星都只存 `kaka-math-v1`；唔用星星買關卡。

## 視覺風格（多姿多彩卡通太空，仍係原創小鹿宇宙）

### 原則

- 同一個宇宙：**小鹿 + 太空冒險**；唔用迪士尼／彼思／KooBits／其他教材角色。
- 數理要比認字「更彩、更卡通、更有旅程感」——夜空底仍然深，但**前景元素好豐富色**。
- 同認字／字母隊共用字體同大 tap（`Fredoka` + `Noto Sans TC`，≥72px）；數學用獨立 `css/math.css`。
- 無登入、無廣告卡、無儀表板感；hub 第一眼係「一粒大星球 + 小鹿 + 出發」，唔係功能牆。

### 氣氛差異

| 模組 | 氣氛 | 色彩策略 |
|------|------|----------|
| 認字 | 深藍太空 + teal／mint | 克制 |
| 字母隊 | 太空底圖 + 彩色字母磚 | 字母本身帶色 |
| **數理** | 夜空 + **八色星球旅程** + 卡通導遊小鹿 | 每星一個主色；金星塵做答啱 |

### 調色（數理專用，避免「AI 紫光」同亂 glow）

底：沿用 `--space-deep` 夜空。  
**彩度上限（已拍板）：每屏以「當前星球主色」為主 + 答啱用金星塵。**  
旅程整體仍然多姿多彩（八星八色），但同一時間唔好變成彩虹大雜燴——玩法區嘅第二色只用主色嘅深淺／鄰近色，或者極克制嘅對比（例如分類左右用主色淺／深兩檔），唔另開第三、第四個搶眼色相。

星球主色（示例，實作可微調）：

| 星球 | 技能 | 主色感覺 |
|------|------|----------|
| 數數星 | 數數 | 暖金／蜜糖黃 |
| 多少星 | 邊多邊少 | 珊瑚粉 |
| 比較星 | 大細長短 | 天藍 |
| 形狀星 | 形狀 | 薄荷綠 |
| 分類星 | 分類 | 橙橘 |
| 規律星 | 規律 | 檸檬黃綠 |
| 位置星 | 位置 | 青綠 |
| 序數星 | 序數 | 桃色 |

答啱：金星塵／小星星彈出（跨星球共用，唔算「第二主色」）。答錯：唔用刺眼紅叉；用柔和搖一搖 + 小鹿「諗吓」表情。

### 卡通角色同元素（原創，可 CSS／SVG／emoji 混用）

1. **導遊小鹿（數理專用，更 Q）** — 唔直接複用主頁鹿造型；數理有一套更圓潤、臉更大、四肢短少少嘅原創卡通小鹿（可加太空小圍巾／耳罩）。表情：待機浮動、答啱跳躍、答錯歪頭、飛行開心。全程陪伴，唔霸佔題目區。仍屬同一「小鹿太空」宇宙，只係數理模組造型更幼齡可愛。
2. **八粒星球** — 每粒有簡單「星球臉／花紋」（環、斑點、條紋），點亮後有光環線，未到訪用灰／淡彩。
3. **小飛船座位** — hub 用嚟「出發」；飛行過場係飛船＋星塵尾，約 1.5–2.5 秒。
4. **數量物件** — 水果／星星／小石頭／小火箭等（系統 emoji 或扁平卡通 SVG）；數數時可逐粒彈入。
5. **分類盒** — 可愛太空貨箱／傳送門兩格，唔係乾枯表格。
6. **規律格** — 缺格有呼吸脈衝，吸引撳／拖。
7. **數字泡泡** — 揀數時用圓潤泡泡掣（大字），唔用考試紙風格。

美術優先級：MVP 用 **CSS 形狀 + emoji + 少量原創 SVG**；之後先加插畫 JPG（似字母隊 hero），保持無 build。

### 動畫語言（要「有風格」，但唔嘈）

至少落地呢組「招牌動作」（可 `prefers-reduced-motion` 時改淡入）：

| 名 | 何時 | 感覺 |
|----|------|------|
| `deer-bob` | hub／學頁待機 | 輕上下浮動 |
| `planet-breathe` | 當前星球 | 緩慢漲縮 |
| `count-pop` | 數數出示物件 | 逐粒 scale-in |
| `snap-in` | 拖入分類／規律格 | 磁吸到位 |
| `cheer-burst` | 答啱 | 小鹿跳 + 金星塵（沿用／強化 `star-burst`） |
| `soft-wobble` | 答錯 | 輕搖，無罰 |
| `warp-hop` | 點亮後去下一星 | 短飛行＋星塵尾 |

原則：同一時間主要一個焦點動畫；循環動畫要慢、輕；過場短過 3 秒。唔堆多層 neon glow、唔用長劇情過場。

### 畫面語言（互動）

- Hub：大星球名（繁中）+「出發」；少字。
- 學習頁：物件要數得到、拖得到；粵語短講；小鹿喺角落點頭。
- 答啱：卡通慶祝 + 溫柔粵語。
- 答錯：「再數一次」＋可閃正確集合；小鹿歪頭鼓勵。

### 文案語氣

- 繁體中文 UI；語音優先 `zh-HK`。
- 短句、鼓勵、無比較／無「好蠢」。
- 旅程用語：「登陸數數星」「點亮喇！去下一粒？」；面試：「試吓呢題」（唔好「考試失敗」）。

## Phase 1 技能（8 項，對齊幼階＋面試常見入口）

借 KooBits 小一「入口課題」再幼一層；**唔做**位值到 100、銀碼、厘米、月曆深學。

1. **數數** — 1–10（之後擴 1–20）：物件對應數量  
2. **邊多邊少** — 兩堆比較；一樣多  
3. **大細／長短／高矮** — 視覺比較（可同認字「相反」呼應，但玩法係比較唔係認字）  
4. **形狀** — 圓、三角、方（之後先加）  
5. **分類** — 按顏色／種類拖入兩盒  
6. **規律** — 簡單 AB／ABC 缺格  
7. **位置** — 上／下／前／後／左／右（聽指令揀圖）  
8. **序數** — 第一～第五（排隊動物／星球）

每項：先學 3–5 張 → 一種玩法即可上線；再補第二種玩法。

## 教學法（借 KooBits，落地成本低）

- **CPA**：Concrete（emoji 物件）→ Pictorial（點點／簡單圖）→ Abstract（數字符號）— Phase 1 以 C／P 為主，抽象數字只做選項。  
- **每日短 session**：目標 5–10 分鐘（細過 KooBits 嘅 20 分鐘）。  
- **小勝利**：沿用每日星星上限 10；答啱 +1。  
- **卡住有階梯**：錯 → 溫柔提示 → 可再聽題；唔彈長教學片（4 歲注意力）。  
- **螺旋**：舊技能間歇再抽（實作後再加權重）。

## Agent 工作方式

- **規格／討論**：以本檔 + `AGENTS.md`「數學（獨立頁）」為準。  
- **實作**：另開 branch（如 `cursor/math-mvp-…`），先獨立 `math.html` 骨架，再逐個玩法；**唔好**仿字母隊把 screens 併入 `index.html`。  
- **預覽**：Cloud Agent 環境會起 `python3 -m http.server 5173`（見 `.cursor/environment.json`）；開 `/math.html`。
