## 視覺風格（延續小鹿太空，唔另起品牌）

### 原則

- 同一個宇宙：**小鹿 + 太空冒險**；唔用迪士尼／彼思／KooBits 角色。
- 同認字／字母隊共用 CSS 變數、`Fredoka` + `Noto Sans TC`、大 tap target（≥72px）。
- 數學模組用**獨立 CSS**（如 `css/math.css`），參考 phonics：可加層氛圍，唔改壞 `styles.css`。
- 無登入、無廣告卡、無儀表板感；第一屏係一個清楚入口，唔係功能牆。

### 氣氛差異（同另外兩個模組分開）

| 模組 | 氣氛 | 提示色 |
|------|------|--------|
| 認字 | 深藍太空 + teal／mint | 現有 |
| 字母隊 | 太空底圖 + 彩色字母 | 現有 phonics |
| **數理** | 同一夜空，加**星座／行星軌道**輕層；數字同數量用 **金＋薄荷** | `--gold` / `--mint`；慎用 coral 做錯感 |

### 畫面語言

- **技能卡**：大 emoji（🍎⭐🔵）+ 二字～四字繁中名；少字。
- **學習頁**：物件要「數得到、拖得到」——優先系統 Emoji／簡單 SVG 點點，唔靠長片。
- **答啱**：金星閃一下 + 溫柔粵語（沿用現有 feedback 風格）。
- **答錯**：無紅叉羞辱；輕提示「再數一次」／短暫展示正確集合。
- **動效**：2–3 個有意圖嘅（卡入場、答啱彈星、技能點亮）；唔加 glow 堆疊、唔用紫系漸變主題。

### 文案語氣

- 繁體中文 UI；語音優先 `zh-HK`。
- 短句、鼓勵、無比較／無「好蠢」。
- 面試模式文案要溫柔（「試吓呢題」），唔好「模擬考試失敗」。

## Phase 1 技能（8 項，對齊幼階＋面試常見入口）

借 KooBits 小一「入口課題」再幼一層；**唔做**位值到 100、銀碼、厘米、月曆深學。

1. **數數** — 1–10（之後擴 1–20）：物件對應數量  
2. **邊多邊少** — 兩堆比較；一樣多  
3. **大細／長短／高矮** — 視覺比較（可同認字「相反」呼應，但玩法係比較唔係認字）  
4. **形狀** — 圓、三角、方（之後先加）  
5. **分類** — 按顏色／種類拖入兩盒  
6. **規律** — 簡單 AB／ABC 缺格  
7. **位置** — 上／下／前／後／左／右（聽指令揀圖）  
8. **序數** — 第一～第五（排隊動物／星球）

每項：先學 3–5 張 → 一種玩法即可上線；再補第二種玩法。

## 教學法（借 KooBits，落地成本低）

- **CPA**：Concrete（emoji 物件）→ Pictorial（點點／簡單圖）→ Abstract（數字符號）— Phase 1 以 C／P 為主，抽象數字只做選項。  
- **每日短 session**：目標 5–10 分鐘（細過 KooBits 嘅 20 分鐘）。  
- **小勝利**：沿用每日星星上限 10；答啱 +1。  
- **卡住有階梯**：錯 → 溫柔提示 → 可再聽題；唔彈長教學片（4 歲注意力）。  
- **螺旋**：舊技能間歇再抽（實作後再加權重）。
