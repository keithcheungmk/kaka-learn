# 卡卡學寫字 · EDB 正體筆順核對（十章）

對照 [香港小學學習字詞表](https://www.edbchinese.hk/lexlist_ch/) 同附錄《常用字字形表》正體。HanziWriter 只能食 Make Me a Hanzi／`hanzi-writer-data` 嘅 SVG path；EDB 網站得動畫、冇公開 path，所以**唔好手造假筆順**。

## 來源

- 字形／筆順 path：`hanzi-writer-data` 2.0.1（繁體字面）
- 筆畫數：`edbStrokeCount` 對齊實際 stroke path 數；入門／身體等舊字已對過《常用字字形表》正體
- 課程：第 1 章入門；第 2–7 章自然／土地（含「禾」）／方向／光／動植物／動作；第 8–10 章屋企、身體、衣物

## 已知視覺差

電腦楷書同 EDB 動畫嘅起筆位置／粗幼會有少少視覺差；唔可以為求「完全一樣」而手改 path。新加字（木水火土田石里金玉禾川……）同樣用套件繁體 path，日後若 EDB 有公開 path 再逐字覆核。
