## P0 — 必須先修

### 1. 「學完喇・去玩玩」第一張已經出現

`#learn-finish-row` 用 HTML `hidden`，但同時有 `.btn-row { display: flex }`。Author CSS 會蓋過 `[hidden]` 嘅 `display: none`，所以學習頁**第一張**已經見到「去玩玩」。

實測：顏色 1/10、紅輯 1/212 都見到呢粒掣。

影響：4 歲可以跳過成個先學流程；紅輯 212 張卡變成永遠學唔完、又永遠有捷徑。

修法：`css/styles.css` 加 `.btn-row[hidden] { display: none !important; }`（或 JS 用 class 而唔用 `hidden`）。侵入細、只改認字 CSS／學習頁。

### 2. 「砌一砌」淡色格已經印住答案

格內 `.build-ghost` 用低透明度顯示正確漢字。4 歲只要照抄淡字，唔使認圖。

修法：空格淨顯示框／序號／「？」；或者只喺答錯兩次之後先出提示。改 `js/app.js` `renderBuildSlots` + `.build-ghost`。中等侵入。

### 3. 相反詞聽一聽：答錯會讀出正確答案

`onListenPick` 錯咗之後 `speakTerm(answerTerm)`。普通聽音模式 prompt＝target，等於再播題目，合理。  
**相反位置** target 係相反詞，等於直接講「答案係『小』」。

修法：錯咗只重播 `prompt.term`。改 `js/app.js` 十行內。侵入細。

### 4. 桌面／TV 四揀一變成 3+1 歪格

`.card-grid` 預設 2 欄；`min-width: 800px` 先變 3 欄。四個選項喺闊螢幕排成三加一，空位好大、視線唔均衡。iPad 直向 2×2 反而好啲。

修法：考試卡固定 2×2；或者 4 個用 2×2、3 個先用 3 欄。改 `css/styles.css`。侵入細。

### 5. 主頁字母隊入口係「隱形圓」

字母隊掛喺左上角 `.brand-orbit`，**冇字、冇圖**，淨係 `aria-label`。4 歲同家長都當 logo。認字／數理先有大掣。

修法：主頁三個入口一排（認字／字母隊／數理），logo 唔好當秘密掣。改 `index.html` + 少少 CSS。侵入細，唔好改字母隊遊戲邏輯。

## P1 — 約 4 歲體驗（認字核心）

### 6. 主題牆 30 格，最難嘅紅／橙輯排最前

實測主題卡約 30 個。第一、二格係紅輯、橙輯（抽象虛詞、212／181 張）。K2 小朋友好易誤入「全部紅輯」，進度變成 **1/212**。

建議：

- 主題分層：**今日好學**（顏色、家庭、動物、食物）→ **日常生活** → **書本溫習（紅／橙輯）**。
- 紅／橙輯卡加「要同爸爸媽媽一齊」標記。
- 「全部紅輯」唔好做預設大卡；或者要長按／家長確認。

改 `js/words.js` `TOPICS` 次序 + `js/app.js` `renderTopics`。中等侵入。

### 7. 一次學晒成個主題先准考（設計如此，但 hidden bug 令佢失效）

修完 P0-1 之後，顏色 10 張 OK，動物園 28 張已經嫌長，紅輯 212 張唔適合 4 歲一次過。

建議每 Round **5–8 張**先學再考；「再學下一批」。數學模組已經有 0/5 進度，認字反而無限連題、無「今輪完成」。

改 `js/app.js` 學習／出題抽樣。中等侵入。

### 8. 考試無限出題，滿星之後仲喺度考

答啱先加星，每日 10 粒硬上限（正確）。但滿星只換一句「今日星星滿晒」，題目繼續出、無「今日學完喇、返主題」。4 歲唔知幾時停。

建議：每模式 5 題一輪 → 慶祝 → 再玩／返主題。同數理節奏對齊。改 `js/app.js`。中等侵入。

### 9. 「配一配」唔自動讀字

聽一聽會播粵語；睇圖模式完全靜音，4 歲要自己對 emoji。AGENTS.md 寫「模式 B 必須維持先撳字 → 再撳圖」，而家實作係「中間出圖、再揀漢字」——**規格同程式已經分叉**。

要產品決定：

- A：維持而家「睇圖揀字」（簡單、一撳），但入場自動讀一次目標詞；或  
- B：改返兩步「先撳字、再撳圖」。

無論邊個，都要改 AGENTS.md／README 其中一邊，唔好兩套講法。改 `js/app.js` + 文件。中等。

### 10. 砌一砌對 4 歲過難／過易同時存在

- 過易：淡字洩答案（P0-2）。
- 過難：職業「環境保護主任」6 字、港式「肥牛烏冬」4 字；字池 8 個形近字。
- 單字詞（紅輯「的／了」）只得一格，變成無遊戲。

建議：主題詞先砌 1–2 字；長職稱跳過或改配對；虛詞唔好入砌字模式。改 `js/app.js` `startBuildRound`。中等。

### 11. Mac mini + TV：無遙控焦點、無全螢幕

只有 `:active`，冇明顯 `:focus-visible`。電視遙控／鍵盤幾乎唔識而家撳邊。家長掣 56px 貼底右，電視過掃描可能切走。

建議：大焦點環、方向鍵移卡片、可選全螢幕。改 CSS + 少少 JS。中等。

### 12. 粵語 TTS 好易跌去普通話

`speech.js` 優先 `zh-HK` → yue → **zh-TW** → 任何 `zh`。Mac mini／Android／無粵語聲線嘅機，會用台灣／普通話讀「屋企、的士、巴士」，同家庭語言衝突。

建議：偵測唔到粵語就顯示「呢部機冇廣東話聲線」＋家長提示；唔好默默用國語。可選預錄短音（好似字母隊 phoneme mp3）。改 `js/speech.js`。中等；預錄就大啲。

### 13. 紅輯「全書 wordIds」同「12 本書」對唔齊

### 14. 重複「老師」死 id

`laoshi` 同 `laoshi_job` 都係「老師」。`laoshi` **冇任何主題引用**，但家長字詞開關會出現兩個「老師」。

修法：刪 `laoshi` 或合併。改 `js/words.js`。細。

### 15. Emoji 撞車，4 歲分唔開

同一圖代表多個詞，配一配／學習會靠猜：

- 🛏️：睡房、床、枕頭、被子（再加紅輯「蓋」）
- 🪑：椅子、桌子、坐
- 🦕：六隻恐龍共用（暴龍等有真實相，其餘無）
- 👃：鼻子、香、聞
- 🥤：渴、水壺、杯子、喝
- ✋：紅輯「有」用舉手（語意唔啱）
- 🎃：南瓜（萬聖節燈，唔係菜）
- 🧸：積木（熊仔，唔係積木）
- 🥬：白菜（生菜）
- 🦌：四隻鹿靠 badge；Linux／舊 Android 駝鹿 🫎 可能方塊

建議：屋企大件改實物相或更分得開嘅圖；虛詞（的／了／嗎）唔好強行 emoji，跟 AGENTS「單字卡大漢字＋讀音」即可。改 `js/words.js` + 可選 `assets/`。中等。

### 16. 無粵拼／讀音提示

學習卡只有漢字＋圖。TTS 失敗或聲線錯（P1-12）時，家長都唔知點讀。紅輯單字卡尤其需要。

建議：可選顯示粵拼（家長開關，預設關，避免干擾認字）。要加資料欄 `jyutping`。改 `words.js` + 學習頁。中等偏大（資料）。

## P3 — 家長區、平台、技術債

### 17. 家長「字詞開關」列出全部 676 詞

240px 高滾動盒、兩欄 checkbox、無搜尋、無按主題篩、無全開／全關。實測要狂滾先搵到「河馬」。  
「完成」喺 modal 最底，字詞盒雖有 max-height，家長仍容易以為關唔到。

建議：按主題摺疊 + 搜尋；預設摺埋。改 `js/app.js` `renderParentPanel`。中等。

### 18. 鹿類重點預設開

`deerFocus: true`。非鹿主題無影響（只加權池內鹿詞），但家長唔知點解動物園會不停抽鹿。家長區文案可再清楚；非鹿主題可忽略呢個開關。細。

### 19. 無 favicon／加主畫面圖示

有 `apple-mobile-web-app-capable`，**無** `apple-touch-icon`、無 `favicon`、無 `manifest`。iPad「加到主畫面」會空白／截圖；瀏覽器 tab 無鹿標。

加 `assets/icons/` + `index.html` link。細。

### 20. Google Fonts 外連

Noto Sans TC + Fredoka 要載 `fonts.googleapis.com`。飛機／弱網／DNS 慢會閃系統字。可 self-host 或系統字優先。細～中。

### 21. Cache bust 手改、版本唔齊

`styles.css?v=20260811c`、`words.js?v=20260815b`、`app.js?v=20260811c`。改 JS 唔改 query 會令 iPad 用舊檔。GitHub Pages 對 `<meta Cache-Control>` 幾乎無效。

建議：每次改相關檔就一齊改 `?v=`，或者單一 `APP_VERSION`。流程／細改。

### 22. 無字詞掌握紀錄

只有每日 10 星。唔知邊個字常錯、無溫習隊列。下一步先加「呢個字答錯次數」（仍存 `kaka-learn-v1`），再先抽弱項。中等，唔好做成複雜 SRS。

### 23. 無自動測試

`words.js` 676 詞、24 本書，只靠 runtime `assertUniqueWordIds`。主題 id 缺失、書卡對唔齊、重複 term，都要人手先發現。

建議：`scripts/` 加一個純 node／python 檢查（unique id、topic 引用、書⊆主題）。細，對之後加詞好有用。

### 24. 其他細項

- 聽一聽卡片 `aria-label` 寫咗漢字，VoiceOver 等於讀答案。
- 相片 `alt="${word.term}"` 同樣洩答案（學習頁 OK，考試翻牌要空 alt）。
- PIN 預設 1234 寫喺畫面（家庭鎖、可接受）；`alert()` 改 PIN 體驗舊。
- 字母隊文案用英文逗號「揀一組,先一齊」（認字用中文逗號）。
- 認字同字母隊共用 `kaka-learn-v1` 靜音／PIN；星星只認字加。合理，但主頁星數唔反映數理。
