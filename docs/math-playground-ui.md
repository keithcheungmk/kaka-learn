# 數學遊樂場 UI 與遊戲設計規格

此文件是之後新增或重做數學遊戲的共用基準。個別課題可有不同玩法；共用的是易讀版面、淺色遊樂園風格、情境引入和清楚的回饋節奏。

以下是設計目標；並非所有現有遊戲已達到。2026-10-28 首階段整理主題入口，將數數遊戲改為故事圖、物件板與答案區，並修正數數回饋。生活數學入口現已逐項說明玩法；答錯會按題型提供策略提示，第二次錯誤會補上示範答案，並朗讀提示。長短題以家居物品對齊 0 cm，在 0–20 cm 刻度尺上比較；這仍是看圖比較遊戲，未取代完整的手動拉尺量度課題。其他遊戲的情境與互動仍需逐項改造和驗收。

## 入口和資訊架構

- 玩家由「卡卡數學遊樂場」進入，以學習主題分類，例如數數、加減、時間、生活數學。
- 不再用星球名稱或行星圖示分類數學內容。內部儲存識別碼可保留，以延續既有星星、關卡和進度資料。
- 每張遊戲卡用一個明確主題名、一句小朋友看得明的玩法，以及熟悉的原生 Emoji 或情境小圖。
- 入口可上下捲動；遊戲開始後即直接進入題目，不要求孩子先讀長篇說明。

## 視覺與版面

- 使用遊樂園的淺白、柔和色彩：淺藍／白色表面、深藍文字、綠色學習提示、暖黃色主動作。文字要有足夠對比。
- 以 iPad 橫向作主要版面：頁首及題目提示在上，下面最多三個清楚區域：「故事／生活情境」、「主要操作學習板」、「答案與回饋」。操作學習板佔最大空間。
- iPad 直向縮窄版面：情境與操作板並排，答案區放在下面；須配合既有 iPad 一屏遊戲契約，不可溢出或藏起操作。手機直向改為「情境 → 操作板 → 答案」垂直排列，可以捲動，不能裁走提示、答案、下一題按鈕或操作內容。
- 情境圖只用作簡短背景故事或海報，可裁切顯示；題目物件、數量、尺刻度、鐘面、金額及答案必須在獨立的高對比操作區呈現。
- 不以動畫作理解前提。動效只作短暫回饋，並尊重減少動態設定。
- 主題 Emoji 使用 iPhone／iPad 原生彩色 Emoji。需要較一致的生活情景時，使用原創無字插圖，不複製外部品牌人物或素材。

## 教學流程與互動

每輪依以下節奏走，按數學目標調整每一步的實際互動：

1. 一句簡短粵語交代孩子正在幫忙做甚麼。
2. 顯示具體物件、圖片或可操作模型，讓孩子先觀察或動手。
3. 用短提示引導策略，例如五個一組、湊十、看尺的整十刻度、沿鐘面轉針。
4. 讓孩子用觸控操作；任何拖放操作都要有點按／按鈕替代方法。
5. 作答後立即肯定正確答案；答錯時溫和地示範和拆步，不只顯示「錯誤」。
6. 留出足夠閱讀及聽回饋的時間，再讓孩子自行前往下一題。

避免把每種主題改成同一種三選一。玩法應對應概念本身：數數可逐件點數／分組，分類可拖進分類區，規律可補下一件，量度可對齊零點讀刻度，鐘面可直接移動指針，購物可選硬幣並合計。

## 文案與聲音

- 使用自然、簡短的香港粵語口語；一個提示只講一件事，避免學術術語和長段旁白。
- 語音與螢幕上的步驟一致；答案回饋應留在畫面，不能在語音未播完時跳題。
- 「厘米」、「分鐘」、「元」等單位要在實際物件或答案旁明確呈現。
- 發音不自然時優先用已核實的固定錄音；裝置 TTS 只作可理解的後備。

## 第一階段：讀厘米

- 先教短物件的 0–10 cm，再進到 10–20 cm；每題只問讀出一件物品的長度。
- 尺上的 0 cm 必須貼齊物件起點；用整十刻度作參照，再數尾端後的小格。
- 首輪物件用擦膠和蠟筆，之後加入鉛筆、玩具車和小熊；答案選項只用相差 1–2 cm 的讀數，避免變成無關的猜答案。
- 答錯先提醒對齊 0 cm 及找整十刻度；第二次再按實際長度拆成「10 cm 加幾格」，或由 0 cm 數起。
- 目前範圍是圖片式 20 cm 直尺讀數練習；捲尺、門邊及更長物件留待後續關卡，不能把本關描述成實際拖動捲尺量度。

## 交付檢查

- 確認 iPad Pro 11 吋橫向 1210×834、直向 834×1210、iPhone 16 Pro Max 直向 430×932：沒有橫向溢出、主要內容互相遮擋或答案被裁切。
- 互動控制至少 44px；長短中文、英文和普通話字串都能換行。
- 逐題確認題目、正解、干擾答案、視覺數量及講解內容一致。
- 裝置預覽與自動檢查分開記錄；桌面視窗縮放不能當成 iPad 真機驗收。
