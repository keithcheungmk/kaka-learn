# 卡卡一家・故事小隊（第一版）

第一版包含六位固定角色、10篇原創短故事、每篇6頁、普通話逐頁朗讀、故事末的聽詞選擇＋打亂詞塊砌句，以及每篇一顆完成星。故事詞彙參考紅輯讀本認字卡；故事句子和情節為原創。每篇把 `bookWords`、`extensionWords` 和各頁 `learn` 分開，避免把場景新詞誤稱為書本原詞。

## 人物連續性

請先讀 `docs/family-story-character-bible.md`。六人共用同一身高基線：卡卡106 cm、禧禧約96 cm、蛙蛙155 cm、姑姑161 cm、傑叔叔170 cm、堯叔叔175 cm。服裝、髮型及辨識特徵以 `assets/family-stories/characters/` 角色三視圖為準。每格圖在網頁外另配句子和對白，插圖不含文字。

## 音訊與玩法

朗讀使用瀏覽器 `SpeechSynthesis` 的 zh-CN 語音，速度設為正常值；每頁朗讀句子和對白，聽音遊戲讀目標詞。這一版沒有預錄音檔，因此瀏覽器沒有普通話語音時，裝置需提供相應系統語音。

讀完六頁後，學生先聽詞選答案，再從混合詞池中排出最後一頁句子並按「提交句子」。兩項完成後才以 `localStorage` 記錄該故事的一顆星；重玩不重複加星。

## 驗收

執行 `python3 scripts/check-family-stories.py`。檢查10篇故事、6頁數量、讀本詞是否確實存在於引用認字卡、每頁 `tiles` 能重組原句、學習詞有來源分類，以及每頁插圖資產存在。
