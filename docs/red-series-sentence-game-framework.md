# 紅輯「按書頁砌句」遊戲框架

## 目的

本文件定義紅輯書本遊戲的內容準備、遊戲流程、成功檢查及驗收標準。目標係讓 K2 小朋友看得到真實書頁、讀得到原句，將句子拆成自然詞組後重新排好；唔係由全書字卡抽字，再猜某個詞同圖片有冇關係。

## 目前狀態與問題

舊版 `js/book-scene-demo.js` 曾用 hard-coded 全書詞表抽選項，會出現「誰／叫／貓／誰在叫」等不屬該頁原句的詞卡。新版題目改由獨立、可追溯的 `sentence-game-data.mjs` 提供；`story-page-hq-manifest.json` 的圖像／字卡資料不會被誤當逐頁句子答案。

只有標示 `sourceVerified: true` 並逐字對過原件的書頁才可進正式砌句遊戲；其餘維持預覽，不可由字卡、圖片或 OCR 自行補造句子。

## 核心內容規則

1. **原書頁是真實來源**：每個題目必須記錄書名、PDF 頁碼及衍生頁面圖路徑；不使用認字卡頁、封面／介紹頁充當故事頁。
2. **句子須人工核實**：抄錄需與原書逐字對照；標點、重複詞、語氣詞及繁體字形均保留。OCR 只作草稿，不是核實證據。
3. **答案必須由該頁原句產生**：不得用同一本書其他頁的字卡詞補成一句，也不得把不在原句的字當正確答案。
4. **按書頁／跨頁及語意切詞組**：每個實際書頁或完整跨頁作一關，遵照原書閱讀方向（通常左至右）；不可把一個跨頁左右頁拆成關卡。依語意切自然詞組，長跨頁可以有 8–12 組，短句保留實際組數，不拆字、不湊題。原文重複詞要逐次保留；若版面有未完成句，只納入可獨立核實的完整句，不猜後文。
5. **干擾項要可判定**：每題加 2–4 個干擾詞；干擾詞不可出現在本題答案中，且不可令另一種句序／答案同樣合理。優先取自同書已核實詞卡或其他已核實頁面。
6. **來源不完整就不開正式題**：句子未核實、頁碼未確認或干擾項有歧義時，該頁標為「內容待核實」，不計入正式 10 星流程。

## 每本書的學習流程

每本書的題數由已核實、適合遊戲的實際書頁／跨頁決定，不設硬性題數，不可為湊題數拆頁、重複句子或造題。每個正確詞組收集 1 粒星，單書一輪最多 10 粒；如已核實內容少於十組，應誠實顯示實際星數或維持試點狀態，不可複製題目灌滿十粒。

### 1. 先學：看書頁、讀／聽原句

- 顯示清晰、完整、未裁切的真實故事頁。
- 學習階段顯示核實過的完整原句；按播放可聽完整句子。進入測驗後遮住書上印刷句，避免孩子直接照抄，但保留重聽按鈕。
- 每題資料保留來源頁碼，方便家長／教師追查。

### 2. 將原句拆成自然詞組

例如完整跨頁原句「爸爸一個橙。媽媽一個蘋果。」可按內容切為：

`爸爸｜一個橙｜媽媽｜一個蘋果`

這是一個完整跨頁任務，不可拆成「爸爸一個橙」和「媽媽一個蘋果」兩題。下方選項必須包括這四個正確詞組，再加入 2–4 個干擾詞。正式題目必須先核對整個句子確實出現在來源書頁。

### 3. 排列詞組成句

- 每個自然詞組一個空槽，依原句閱讀順序排列；短句可以只有 2–3 個合理詞組，不硬拆或湊數。
- 小朋友點一下正確詞組，就自動放入下一個空槽；不用再點第二次空槽。
- 支援拖曳作為替代方式；觸控操作不可只依賴拖曳。
- 選錯干擾詞時，溫和提示「再聽一次，找找句子裏的詞語」，不應鎖住遊戲或算作答對。
- 可移除／更換已放入詞組，讓孩子自己修正次序。
- 按「回答」後逐槽核對；整句詞組及次序全對才算完成。

### 4. 回饋、星星及進度

- 每個原文詞組第一次答對後射入 1 粒星；每書一輪最多 10 粒，按實際內容計算，不按題目平均派星。只有一個詞組重複出現時，每次出現都是獨立的一粒星。
- 答錯不加星、不扣已得星，不跳題。
- 答對後先由 KAKA Ranger 逐粒射出星星；每顆落到進度目標即記錄。所有星星落地後才朗讀完整原句；射星、保存及朗讀都完成後才進入下一版。
- 每本書各自儲存進度；切換書本或重新載入，不可串到其他書。
- 完成後按實際已核實任務數顯示星數；只有累積十個詞組時才顯示 10/10，並提供「再玩／返回書本列表」。

## 內容資料格式

建議新增逐頁句子 manifest；現有 `data/book-cards/` 保留作認字卡來源，不可拿它代替句子來源。

```json
{
  "book": "rb_example",
  "title": "示例書名",
  "contentStatus": "verified",
  "questions": [
    {
      "id": "p4-s1",
      "pdfPage": 4,
      "pageImage": "assets/book-scenes/red-series-pages-hq/示例書名-p4.webp",
      "sentence": "爸爸一個橙。媽媽一個蘋果。",
      "sourceVerified": true,
      "chunks": ["爸爸", "一個橙", "媽媽", "一個蘋果"],
      "distractors": ["小狗", "在叫", "一束花"],
      "audio": null,
      "reviewNote": "句子逐字對照 PDF p4"
    }
  ],
  "round": {"taskUnit": "printed-page-or-complete-spread", "starsPerChunk": 1, "starCap": 10}
}
```

### 欄位要求

- `pdfPage`、`pageImage`、`sentence`、`chunks`、`distractors` 必須同時有值，題目才可進正式流程。
- `sourceVerified` 必須為 `true`；如果句子含多行，按原書閱讀順序保留。
- `chunks.join(適當分隔符)` 必須忠實還原 `sentence`（移除標點後比對）；不可遺詞、漏句或改字。原句有重複詞時，選項須以獨立 ID 區分，不能去重答案；判題按可見詞組文字和所在句序比對，不能因為兩張顯示相同的詞卡 ID 不同而誤判。
- 干擾詞不可以與答案組相同，答案和干擾選項應洗牌；正確順序仍由 `chunks` 唯一決定。
- 若頁面只有圖片而無可核實句子，可做「看圖認字」預覽，但不可混入砌句測驗。

## 建置步驟

1. **盤點 PDF**：列出每本頁數，逐頁標記封面、活動指引、字卡、故事頁；排除封面／字卡頁。
2. **挑故事頁**：選擇圖像和文字清楚、句子完整的頁面；記錄 PDF 實際頁碼。
3. **人工抄句及複核**：建立句子草稿後與 PDF 對照；第二次校對只檢查字形、次序、標點和頁碼。
4. **切詞組及設干擾項**：按頁面實際語意切組並保留重複詞；不得因為技術上方便而去重。干擾字要來自已核實內容，並由另一人檢查無雙重答案。
5. **接入共用引擎**：引擎只讀逐頁／跨頁題目資料；不再從 `RED_BOOKS` 全書字表索引生成頁面答案。內容與 UI 分離；每個選項用穩定 ID，支援句中重複詞。
6. **本地測試**：跑 `node scripts/test-book-scene-demo.mjs`、全輪 touch Chromium 玩法 smoke 及 `python3 scripts/check-invariants.py`；流程／版面改動按 `AGENTS.md` 跑家庭 viewport smoke，必須完成全輪及再玩，不可只測第一題。
7. **內容驗收**：逐本抽看每題的原書頁、句子、詞組、干擾項及朗讀順序。任何一項對不上都不部署該題。
8. **部署檢查**：CI 通過後部署；在 iPad 橫向和 iPhone 開新 cache-bust URL，確認資產、互動及語音用的是同一版本。

## 成功檢視清單

### 內容正確性

- [ ] 題目圖片是該本書真正故事頁，而非封面、介紹或獨立字卡頁。
- [ ] 每句與 PDF 頁面逐字一致，能指出書名及頁碼。
- [ ] 詞組可以按唯一順序還原原句；原句內所有詞語均有對應，沒有額外答案。
- [ ] 干擾項不在本句答案中，且不會形成另一個同樣合理的句子。
- [ ] 顯示、播放的句子、槽位順序和回饋內容完全一致。

### 玩法正確性

- [ ] 點正確字一次即可進入下一個空槽；不是要點字再點槽。
- [ ] 拖放可用；錯字不佔槽、不加星，且有明確溫和提示。
- [ ] 答案詞組次序錯會判錯；調整後可以再答。
- [ ] 每粒星落地即保存；全部星落地後才播放完整句，語音完成後才換頁。
- [ ] 一個書頁／完整跨頁一關；不拆分、不以重複內容湊題；每組 1 星，單輪最多 10 星，重新整理／換書後進度獨立且正確。
- [ ] 答對時每顆星均由 Ranger 射出並落到進度目標；星數只在落地時更新。
- [ ] 未完成句、封面／介紹／字卡頁有排除標記，不混入故事句子遊戲。

### 版面及資源

- [ ] 真實書頁清晰、完整顯示，無拉伸、裁切或文字被 badge 遮蓋。
- [ ] iPad Pro 11 橫向 `1210×834` 一屏能看清書頁、答案槽、字詞選項及提交掣；無垂直捲動、重疊或橫向溢出。
- [ ] iPad 直向 `834×1210` 使用直向單欄／手機式排列，無垂直捲動、重疊／裁切；iPhone `430×932` 無重疊／裁切，內容過長時可垂直捲動。
- [ ] 觸控掣至少 44×44px；字詞不會因為換行而被遮住。
- [ ] 無破圖、404、白屏或 console error。

## 自動化驗收要求

`scripts/test-book-scene-demo.mjs` 至少檢查：

1. 所有正式題均有有效書名、PDF 頁碼和存在的圖片資產。
2. `sourceVerified === true`，句子／詞組／干擾字非空。
3. 詞組排序還原原句（忽略標點和分隔符後一致）。
4. 干擾項不等於任一正確詞組，干擾項彼此不重複；答案詞組可重複，但每次出現須有獨立選項 ID。
5. 每關對應一個已核實書頁／完整跨頁；詞組數和星數匹配、總上限 10；不要求固定題數或複製題目。
6. 引擎按當前題目顯示 options；不再將全書字卡當作本頁答案池。
7. 點按自動填槽、選錯、錯序、修正後答對、逐粒射星及落地保存、星星完畢後才開始語音、語音完成後才換頁、十星封頂、Profile 隔離、重載續玩與重新開始均有互動測試。

## 驗收與開放條件

- **內容驗收者**：中文內容負責人確認句子、頁碼、切詞與干擾項。
- **玩法驗收者**：中文遊戲負責人確認點按／拖放、判題、語音、星星和進度。
- **合併閘門**：內容檢查與互動測試全綠、家庭 viewport smoke 全綠、CI 全綠，才可 merge/deploy。
- 未達條件時標記為「預覽／待核實」，不可以宣稱該本已完成砌句遊戲。
