# 試行 memo：睇完即砌呢個字

給 Keith／卡卡試一次用。未改學習頁流程；呢份係計劃。

## 簡單嚟講

學習頁上面睇圖、聽廣東話。下面可以有擾亂字，撳（或拉）入淡色格砌返呢一個詞。砌完可以下一張。

**但唔會迫卡卡每張都砌完先准走。** 下一張永遠開住。想砌就砌，不耐煩就翻去下一個。

## 兩個觀察點樣平衡

**1. 耐性（4 歲好快嫌長）**
- 砌係邀請，唔係關卡。
- 以**撳一下入格**為主（撳字池啱嘅字 → 自動入下一格），唔使先揀再撳格，更唔使每隻字都拖。
- 拖仍然得，但唔係必經之路。
- 試行唔加星星，避免變成打機。

**2. iPad 妙控鍵盤一拉就放大畫面**
- 遊戲唔需要放大縮細。
- App 鎖死 pinch／trackpad 縮放（認字／字母隊／數理同一頁）。
- 砌練習鼓勵用撳，減少兩指誤觸。

## 卡卡會見到（試行）

1. 學習卡：圖 + 漢字 + 聽（同而家）。
2. 下面有字池（有擾亂字）同淡色格；想砌就撳啱嘅字入去。
3. 砌錯：溫柔再試，唔換詞。
4. 隨時「下一張」；唔砌都得。
5. 最後一張之後仍然有聽一聽／配一配溫習。

## 第一次只試咁少

- **一個主題：** 情緒（6 詞）。
- 相反位置、紅／橙輯先唔試。
- 淡色格、字池干擾唔改。
- 聽一聽／配一配／字母隊／數理玩法唔改。

## 你點試

iPad（有妙控鍵盤都試吓拉同撳）：睇佢會唔會自己撳字、會唔會跳過、畫面會唔會再放大。試完三句：想繼續／想改邊樣／想停。
