# 試行 memo：睇完即砌呢個字

給 Keith／卡卡試一次用。未改 app；呢份只係試行計劃。

## 而家 vs 試行

**而家：** 先翻完主題全部學習卡 → 去玩玩 → 先揀砌一砌 → 隨機抽字砌。

**試行：** 每張學習卡變成「睇 → 聽 → 砌呢一個詞」；砌完先下一張。砌一砌當**練習**，唔當遊戲／考試。

## 卡卡會見到嘅一步

1. 學習卡：圖 + 漢字 + 廣東話（同而家一樣）。
2. 同一頁下面出現砌一砌：淡色格係呢個詞、字池有干擾字；拖或撳，由左到右。
3. 砌錯：溫柔再試，唔清零、唔換詞。
4. 砌啱：讀一次成個詞，停一停望自己砌好嘅字，然後「下一張」。
5. 最後一張砌完：仍然有「去玩玩」（聽一聽／配一配做溫習）。砌一砌唔使再喺「去玩玩」入面重做同一套。

## 第一次只試咁少

- **一個主題：** 情緒（6 個詞，約 4 歲短 session）。
- **相反位置先唔試**（左右成對，流程唔同）。
- **紅／橙輯先唔試**（單字卡，稍後先諗）。
- **淡色格、字池干擾、拖／撳，全部唔改。**
- **聽一聽／配一配／字母隊／數理唔改。**
- 試行期間砌練習**唔加星星**（避免變成打機攞星；聽／配溫習照舊可以攞星）。

## 你點試（一次 8–12 分鐘）

用 iPad，情緒主題，坐低陪卡卡：

1. 睇佢第一張「開心」會唔會自己伸手去砌，定係想撳下一張走。
2. 砌錯嗰下：面色／會唔會放棄。
3. 6 個詞砌完：仲想唔想「去玩玩」聽／配，定係已經夠。
4. 你自己感覺：會唔會太長、螢幕會唔會太滿（學習卡 + 字池一齊）。

試完只記三句就夠：想繼續／想改邊樣／想停。

## 試完一齊決定

| 見到 | 跟住 |
|------|------|
| 伸手砌、錯咗會再試、唔焗 | 開去其他短主題（顏色、學校用品） |
| 螢幕太滿、唔知先睇定先砌 | 改成：睇完先撳「砌呢個字」先出字池 |
| 6 個已經嫌長 | 每張可跳過砌，或者只砌 3 張 |
| 砌完仲想玩砌一砌 | 「去玩玩」留返砌一砌，當加時練習 |

## 刻意唔做（呢次試行）

- 唔改淡字做空白考試格
- 唔加計時、分數、過關鎖
- 唔把聽一聽／配一配塞入學習卡
- 唔一次過改晒所有主題
